# Live Sports

## Full Description

Stream your favorite live sports with maximum ease and reliability. This plugin continuously aggregates live match links and streams across top global competitions.
No more jumping between apps or websites to hunt for streams.

### ⚠️ For the best streaming experience, using an [ad-blocker](https://adguard.com) is recommended.

## Features

* **Multiview:** Watch up to **6 streams on a single screen**. Perfect for busy matchdays and multiple games at once.
* **Real-Time Match Center:** Stay updated with live scores, real-time match status, upcoming fixtures, schedules, and results.
* **Advanced Search:** Quickly find your favorite teams, leagues, and competitions.


## Global Coverage 🌍
Enjoy live sports coverage from around the world, featuring major professional, collegiate, domestic, and international competitions.
 
### Installation
1. Clone or download this repository.
2. Go to chrome://extensions/ in your
browser.
3.    Enable **Developer mode**.
4.    Click **Load unpacked** and select this project folder.

### Usage
*   Click the extension icon.
*   Select a match
