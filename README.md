# Live Sports & Highlights

Discover and enjoy live sports streams and video highlights with ease. Live Sports apps (Android and Web) and browser extension aggregate links to live match streams and highlights of completed matches across major sports competitions worldwide. The goal is to make it easier to discover and watch sports streams and highlights without constantly switching between websites or apps.

> ⚠️ **Recommended:** Use a reputable [ad blocker](https://adguard.com) for a smoother live sports streaming experience. External streaming websites may contain intrusive advertisements or pop-ups.

## ✨ Features

- **📺 Multiview (Android & Web):** Watch up to **6 streams simultaneously** on a single screen. Ideal for following multiple matches on busy matchdays.
- **⚡ Real-Time Match Center:** Follow live scores, match statuses, upcoming fixtures, schedules, and results.
- **🔗 Live Sport Streams and Video Highlights Aggregation:** Watch live sports and highlights of completed matches in one convenient interface.
- **🌍 Global Sports Coverage:** Explore major professional, collegiate, domestic, and international sports competitions.
- **🔎 Advanced Search:** Quickly find your favorite teams, leagues, and competitions.

## 🚀 Installation & Usage

This repository provides three versions of the project:

- **Chrome Extension** — Run directly in Google Chrome.
- **Android App (APK)** — Install on a compatible Android device.
- **Web App** - Visit the website (no installation required)

Choose your preferred platform below to get started.

## 🧩 Chrome Extension

### 📥 Installation

The Chrome extension can be installed manually from the source code using Chrome's Developer Mode.

1. **Download the source code**
   - Click the green **Code** button at the top of this repository.
   - Select **Download ZIP**.
   - Extract the downloaded ZIP file to a folder on your computer.

2. **Open Chrome Extensions**

   Navigate to `chrome://extensions/` in Google Chrome.

3. **Enable Developer Mode**

   Turn on the **Developer mode** toggle in the top-right corner.

4. **Load the extension**

   - Click **Load unpacked**.
   - Select the extracted project folder that directly contains the `manifest.json` file.

5. **Open the extenson**

   Once installed, the extension should appear on the Chrome Extensions page.

### 🕹️ Usage

1. Click the **Extensions** icon in Chrome's toolbar.
2. Pin Live Sports to your toolbar for convenient access.
3. Click the Live Sports icon to open the extension.
4. Browse available matches, search for competitions, and open streams.

## 🤖 Android App (APK)

### 📥 Installation

The Android version is distributed as an APK file through the repository's GitHub Releases.

1. **Download the APK**

   Open the repository's [Releases](../../releases) page and download the APK from the latest release.

2. **Allow installation from this source**

   If Android blocks the installation, open your device's settings and allow your browser or file manager to install unknown apps.

   The exact setting may vary depending on your Android version and device manufacturer.

3. **Install the app**

   Open your Downloads folder, tap the downloaded APK, and follow the on-screen installation instructions.

4. **Launch the app**

   After installation, find the app in your app drawer and tap its icon to open it.

### 🕹️ Usage

1. Launch Live Sports from your Android device.
2. Browse available matches and competitions.
3. Search for your favorite teams or leagues.
4. Select an available stream or highlights to start watching.
5. Select multiview option to watch up to 6 streams on one screen. Use Landscape for multiview on mobile phones.
